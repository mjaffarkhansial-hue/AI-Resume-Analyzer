# AI Resume Analyzer and Job Matcher

A beginner-friendly, free, local web application built with Python and Streamlit. It compares a resume with a target job description, detects skills, estimates text similarity, highlights skills not detected in the resume, and creates practical improvement suggestions.

## Features

- Upload a PDF resume or paste resume text.
- Paste a job description.
- Extract selectable text from PDFs using PyMuPDF.
- Detect skills using an editable built-in keyword list.
- Calculate TF-IDF cosine similarity.
- Calculate a combined match score.
- Show matched and not-detected skills.
- Generate rule-based improvement suggestions (no paid AI API key).
- Download a plain-text analysis report.

## Requirements

- Windows 10 or Windows 11
- Python 3.10 or newer
- Internet connection for the initial package installation

## Installation on Windows

1. Download and extract this project ZIP.
2. Open the extracted `AI-Resume-Analyzer` folder.
3. Open the folder in Visual Studio Code.
4. Open the VS Code terminal: **Terminal → New Terminal**.
5. Create a virtual environment:

   ```powershell
   py -m venv .venv
   ```

6. Activate it in PowerShell:

   ```powershell
   .\.venv\Scripts\Activate.ps1
   ```

   If PowerShell blocks activation, use Command Prompt instead:

   ```cmd
   .venv\Scripts\activate.bat
   ```

   Or keep PowerShell and run Streamlit with the environment's Python directly:

   ```powershell
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   .\.venv\Scripts\python.exe -m streamlit run app.py
   ```

7. Install dependencies:

   ```powershell
   python -m pip install --upgrade pip
   pip install -r requirements.txt
   ```

8. Start the application:

   ```powershell
   streamlit run app.py
   ```

9. Streamlit will show a local address, normally `http://localhost:8501`. Open it in your browser.

## How to use

1. Upload a text-based PDF resume, or paste resume text.
2. Paste the complete job description.
3. Click **Analyze Resume**.
4. Review the overall match estimate, matched skills, skills not detected, and suggestions.
5. Click **Download analysis report** to save the result.

## How the score works

- Skill coverage = matched skills / skills detected in the job description.
- Text similarity = TF-IDF vectorization followed by cosine similarity.
- When job skills are detected, overall score = 70% skill coverage + 30% text similarity.
- If no skills from the built-in dictionary are found in the job description, the app uses text similarity alone.

The score is an estimate for learning and resume tailoring. It is not an ATS certification or a prediction of hiring success.

## Customize the skills list

Open `job_matcher.py` and add or remove entries in `SKILL_KEYWORDS`. This is useful for adapting the project to law, business, software, marketing, or other job sectors.

## Limitations

- Scanned/image-only PDFs may not contain selectable text. Use OCR separately or paste the resume text manually.
- The built-in skill dictionary is intentionally simple and should be expanded for the target industry.
- Suggestions are rule-based, not generated by a large language model.
- A skill marked as missing was not detected in the provided text; it does not mean the applicant does not have that skill.
- The app does not store uploaded resumes permanently or send them to a third-party AI service.
